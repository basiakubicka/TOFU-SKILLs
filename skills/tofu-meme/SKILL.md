# TOFU Meme

Write a **meme top-of-funnel post in your own voice**: an image or graphic carries the actual joke or point; your text is minimal caption or framing around it. This is the one TOFU archetype where BREVITY is correct, not a defect — resist the urge to pad it into a normal-length post.

**⚠️ Requires a real image.** This skill assumes you have (or are describing) an actual image/graphic/screenshot/meme template. If there's no image, this is the wrong skill — check `tofu-explainer` or a relatable-mirror-adjacent option instead (once that archetype's data review is complete).

---

## Classification — is this actually a Meme post?

Test: does an actual image carry the joke or the point, with the text doing secondary work (caption, light framing, or a short list riding on top)? If there's no real image attached, it is NOT this archetype regardless of how short or joke-like the text is.

## The two sub-variants

### (a) PURE meme — near-zero text, the image IS the payoff
```
[1 line, or two very short lines — the setup or caption]
[the image]
```
Real examples from the golden-dataset pull (structure only, never copy):
- "Vibe coder at 2AM building the next $1B SaaS 😂😂😂" (near-zero text, comic image carries it — 5,841 likes).
- "Chipotle's support bot is free 😂" (a chat screenshot IS the joke — 4,695 likes).
- "$150K/month tokens vs $4.5K for Rohan... Welcome back, Rohan 🫡" (The Office 3-panel meme format — 6,197 likes).

**Judged on LIKES almost exclusively** (median share/like ≈0.03 in the golden pull — this is the purest "like engine" of any TOFU archetype). Do not add a CTA wall or engagement question; it kills the format.

### (b) ELEVATED meme — image + one-line thesis + a tight list
```
[HOOK — 1 line: the thesis the image jokes about]
[the image]

[𝗥𝗢𝗺𝗲 𝗥𝗕𝗹𝗲 short bold header, optional]
→ [tight item]
→ [tight item]
→ [tight item]

[1-line mic drop reframe]
[optional very light engagement question]
```
Real examples (diverse authors, no single-voice skew):
- "3 things to ship products: ☕ Coffee. 🤖 Claude Code. 💵 A good salary." (4-panel comic + tight list, 1,408 likes).
- "🚨 Google Maps went FULLY AGENTIC" + reasons/reflects/iterates bullet riff over a map image (2,535 likes).
- A real example: "This meme has been updated. It is the most accurate thing I've seen about AI." + "AI is giving execution speed to people with ideas who don't know how to lead" + tight 3-item arrow list + "AI + Humans, not AI vs. Humans" reframe (960 likes — see the source examples, archetype 8a).

Adds a LITTLE substance to the joke — heavier text than a pure meme, much lighter than an explainer. Max 3-5 items.

> **Caption pattern reference:** for fixed-word caption/framing templates extracted from the golden dataset (absurd re-elevation, named-phenomenon thesis, corporate-euphemism relabel, "funny because it's true" + list, economics deflation) plus the pure-bucket near-zero discipline, see `references/caption-template-bank.md`. Use it for brevity/framing patterns, not text to copy verbatim.

## Signature voice moves

- **Let the image do the joke.** Never explain the joke in the text ("this is funny because...").
- **Image/source credit.** If the meme template or original graphic isn't yours, credit or note where it's from.
- **For elevated: one clean reframe line**, not a full mic-drop paragraph.

**Floor-check — applies loosely, image-first:** the general checklist in
`<BRAND_DIR>/hook-floor-check.md` was built for text hooks; a meme's real hook is
the image, so text-only loop mechanics apply weakly here. The one part that still
holds: keep the caption concrete over abstract (a named template/subject beats a
vague "this is so relatable" framing) and never resolve the joke's own loop in text —
that IS letting the image do the work, per this skill's core rule above.

---

## Judge this archetype by ITS success metric: LIKES, pure and simple

Both sub-variants win on likes, not shares or comments. A meme that gets comments arguing about it has drifted into contrarian territory; a meme that gets reshared like a resource has drifted into roundup territory. Keep it a pure "I laughed / that's so real" reaction.

## Length target — OVERRIDE of <BRAND_DIR>/linkedin-voice.md's normal TOFU range
- **Pure meme:** 0-40 characters of text. Shorter is correct. Do not pad.
- **Elevated meme:** 150-500 characters. Still far shorter than every other TOFU archetype.

## Humor — OVERRIDE of <BRAND_DIR>/linkedin-voice.md's 2-beat cap
This IS the humor archetype — the whole post is the joke (pure) or built around one (elevated). The normal 2-beat cap and self-deprecation-vs-dry framing don't apply the same way here; let the image and caption be as funny as the actual content warrants. Still: never write the laugh (no `lol/haha/😂` stacked on top of an already-funny image — pick one or the other), never explain the joke.

## Credibility beat — does NOT apply here
Skip it entirely. A credibility line would kill a meme's timing.

## What NOT to do
- ❌ Using this skill when there's no real image — check first.
- ❌ Padding a pure meme with extra text "to be safe."
- ❌ Explaining the joke in the caption.
- ❌ Adding a heavy CTA wall, engagement question, or reframe paragraph to a PURE meme.
- ❌ Sourcing PURE-meme reference examples exclusively from one author (eordax) without noting the skew.

## Output Format
Pattern selection, drafting, and self-critique are **internal**.

**Critique-and-rewrite (single pass, no loop budget for this archetype).** Meme
captions are short by design — a single check-and-tighten pass is enough; the
3-loop budget in `<BRAND_DIR>/linkedin-voice.md` is overkill here since there's no
body to check for reading level/single-point/filler (the image carries the payload).
Write it, run the self-check below, output the revised version.

### 1. The Post (caption + a description/placeholder of the image if none is provided)
**Placeholder discipline (the `[IMAGE: ...]` tag):** when no image is supplied, the placeholder is a SHORT identifying LABEL that names the meme template or subject so the image can be sourced — NOT a narrated description of the gag. One short phrase, ideally under ~10 words; add a `Credit: X` only when the graphic isn't yours. Do not restate the punchline, spell out the joke, or transcribe on-image text in the placeholder — that duplicates the joke in words and violates the "let the image do the joke / never explain it" rule above (a full narration also reads as caption over-explaining). Examples: `[IMAGE: The Office whiteboard 3-panel meme]`, `[IMAGE: "before vs after agents" laptop tweet, @cormachayden_]`, `[IMAGE: dangerously overloaded wall outlet. Credit: Ralph]` — NOT `[IMAGE: The Office three-panel meme where a man points to a whiteboard showing that a company spending $150,000/month on LLM API costs would save money by rehiring junior data scientist Rohan at $4,500/month]`.
